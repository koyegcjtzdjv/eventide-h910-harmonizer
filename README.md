## Overview

Eventide H910 Harmonizer recreates the original 1975 Eventide H910, the world's first digital pitch shifter, with its characteristic digital artifacts and classic pitch manipulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eventide H910 Harmonizer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vintage Pitch** | First-generation pitch shifting with authentic digital artifacts |
| **Delay** | Short delay times for doubling and flanging effects |
| **Detune Mode** | Subtle pitch detuning for classic 1970s lead guitar enhancement |
| **Feedback** | Variable feedback for harmonizer and delay combination effects |
